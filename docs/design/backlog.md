# Design backlog

Sixty-two design items, in the order they are needed. Items DS-01 to DS-18 must be decided before the first line of code (Build step 0); every other item must be finished before the step listed in "Needed by". Each item produces a file in the repo: an ADR in `docs/adr/` for decisions, a specification in `docs/design/` for models and algorithms, or a catalog file for data such as account and movement-type lists. A design item is done when its file exists, it cites the decided items it depends on, and its open points are listed as open questions.

## Add-ons designed after the core

The author's decision (Vinh An Tran, 2026-11-15): the e-invoice provider connection is an add-on, not part of the core, and is designed after the core design is complete. The core keeps the seam it already defines: the regime setting that says whether a type needs an e-invoice, the `issuing` state with its frozen plan and `posting_intent`, `tax.contract.request_e_invoice`, `RecordEInvoiceOutcome`, the external consumer pattern and the package's `EInvoiceValidator` ([ADR-0028](../adr/0028-document-lifecycle-hardening.md) rules 3, 6, 7; [ADR-0027](../adr/0027-cross-cutting-ownership.md) rule 8; [ADR-0013](../adr/0013-outbox-and-events.md) rule 10). The deterministic stub adapter of ADR-0028 rule 12 stays in the core build: the synthetic dataset and the tests run the `issuing` path against it from step 5, including DS-17's `e_invoice_rejected` and `e_invoice_outage` events. Only a production company has the setting off until a provider adapter is installed; its e-invoice-capable types then post through `Post<Type>` like any other posting type.

## Enterprise coverage check (session S1, 2026-11-21)

The chief architect checked the design against what an enterprise-grade ERP needs: organization, finance, operations, cross-cutting mechanisms, data lifecycle and extensibility. The test for each gap was the cost of adding it after the core tables are built. A gap that would change a key, add a required dimension to the journal or to every document, or split a table is closed now or, where the choice belongs to the author or to the ledger DDL of session S2, carries an interim answer and is first in the list (rows 1 to 3); anything that is a new independent table or a nullable column is only listed here.
